Ambiente de desenvolvimento

debug.xml contém configurações adequadas ao estudo local, incluindo console/debug. Não trate essas opções como recomendadas para produção. Prefira escuta local, firewall e credenciais fortes.

Segredos

Não publique e-mails de login, senhas, cookies, tokens, chaves de mapas, logs com identificadores pessoais nem coordenadas reais de terceiros.

Backup

Faça backup consistente do banco H2 com o servidor desligado, além dos arquivos de configuração. Documente restauração em ambiente isolado antes de confiar no procedimento.

Permissões

Revise a relação entre usuários, dispositivos, grupos e compartilhamentos. Uma API que responde HTTP 200 publicamente não significa que endpoints privados devam estar expostos.

Produção

Para implantação real, avalie banco de dados apropriado, TLS, logs, retenção, monitoramento, política de atualização e isolamento de rede. Não exponha o debug.xml à internet.
