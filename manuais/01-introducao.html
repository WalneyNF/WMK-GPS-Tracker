Traccar — Manual técnico 01

Introdução, arquitetura, execução, tradução e testes

O que é o Traccar?

Plataforma de rastreamento GPS: recebe posições de dispositivos por protocolos próprios, mantém usuários, dispositivos, posições, eventos e relatórios. Possui servidor Java e frontend React. O fork está em D:\Ferramentas\traccar.

Estrutura

traccar/
  src/           código Java do servidor
  schema/        estrutura e migrações do banco
  traccar-web/   aplicação React de gerenciamento
  build.gradle   compilação Java
  gradlew.bat    Gradle Wrapper
  debug.xml      configuração local de desenvolvimento
  openapi.yaml   especificação da API
  manuais/       documentação WMK

Como funciona

Dispositivo GPS → protocolo de rede → decodificador do servidor → validação/armazenamento → API REST/WebSocket → navegador React. O GPS físico não é obrigatório para estudar o sistema; dados sintéticos podem ser usados em testes claramente identificados.

Tradução

Existe tradução brasileira em traccar-web/src/resources/l10n/pt_BR.json. Para alterar uma mensagem, localize sua chave, modifique apenas o valor correspondente e teste a interface. Não remova identificadores nem traduções originais.

Execução e testes

O projeto utiliza Gradle 9.8.2 e declara compatibilidade Java 21. Há JDK 23 em D:\jdk, ainda sujeito à validação da compilação. O frontend usa Vite, React e npm.

cd D:\Ferramentas\traccar
.\gradlew.bat compileJava

cd D:\Ferramentas\traccar\traccar-web
npm ci
npm run build

Os comandos dependem de Java e Node configurados. Não afirmar que o servidor está operacional até verificar a porta HTTP, autenticação e persistência.

Integração futura WMK

Traccar continuará independente. Uma integração futura poderá consultar sua API por meio de um gateway seguro, normalizar posições e exibi-las como camada opcional no globo Cesium. Essa integração ainda não está implementada.
