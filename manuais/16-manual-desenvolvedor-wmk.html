Material educativo do fork WMK. As instruções distinguem recursos existentes do Traccar de integrações ainda em desenvolvimento.

1. Estrutura do projeto

O backend do Traccar é desenvolvido em Java, com Gradle. Os diretórios src, schema, templates, docker e openapi.yaml integram o repositório. O frontend React fica no submódulo traccar-web. As personalizações WMK devem ser feitas em branches e commits isolados.

2. Requisitos e compilação

Confira java -version e o JDK exigido pelo build.gradle; não use um JRE antigo como substituto do JDK. No Windows, execute gradlew.bat --version antes do build e gradlew.bat test para testar. Evite modificar o servidor de produção durante a compilação. Nesta revisão, o comando java do PATH apresentou erro em uma instalação Java 8 antiga: o build NÃO foi revalidado.

3. API HTTP existente

A especificação do backend está em openapi.yaml. Consulte GET /api/server para diagnóstico; endpoints de dispositivos e posições geralmente exigem sessão ou credenciais válidas. Confira os esquemas e os métodos na especificação da versão instalada, em vez de assumir que todos os endpoints são públicos.

4. Exemplo JavaScript

fetch('http://127.0.0.1:8082/api/server', {credentials:'include'}).then(async r => {if(!r.ok) throw new Error('HTTP '+r.status); return r.json()}).then(console.log).catch(console.error); Execute no contexto de origem permitido. Não embuta senhas no frontend.

5. Exemplo Python

from urllib.request import urlopen; import json; print(json.load(urlopen('http://127.0.0.1:8082/api/server', timeout=5))). Para recursos protegidos, use autenticação compatível com a versão instalada; nunca armazene credenciais no repositório.

6. Exemplo PHP

$ch=curl_init('http://127.0.0.1:8082/api/server'); curl_setopt_array($ch,[CURLOPT_RETURNTRANSFER=>true,CURLOPT_TIMEOUT=>5]); $body=curl_exec($ch); $status=curl_getinfo($ch,CURLINFO_HTTP_CODE); curl_close($ch); echo $status.' '.$body; Requer PHP com cURL.

7. Contrato de integração WMK

O GPS Tracker permanece independente. O WMK Geo Bridge pode consultar /api/devices e /api/positions e normalizar id, latitude, longitude, speedKmh e timestamp. A aplicação Geo Intelligence pode consumir a Bridge ou outros provedores. Nunca exija que os três serviços estejam ativos para inicializar um deles.

8. Testes e diagnósticos

TR-001: GET /api/server retorna 200. TR-002: autenticação válida e inválida. TR-003: cadastro e listagem de dispositivo autorizado. TR-004: ingestão de posição simulada pelo protocolo correto. TR-005: UI e mapas. TR-006: regressão Java/Gradle. TR-007: integração Bridge. Registre comandos, saída, data e resultado; não confunda teste pendente com aprovado.

9. Frontend e Git

O diretório traccar-web é submódulo, atualmente com alterações locais. Para publicar customizações, crie um fork apropriado do frontend, configure o remoto e atualize o ponteiro do submódulo no servidor. Não execute reset/clean/submodule update --force sem preservar as alterações existentes.

10. Segurança e distribuição

API pública no sentido de documentação não implica acesso irrestrito pela internet. Para disponibilizar rastreamento externo, implemente HTTPS, autenticação, autorização por usuário/dispositivo, limites de requisição, auditoria, controle de retenção e proteção de dados. Respeite Apache 2.0 e os créditos originais.

11. Exercícios de desenvolvimento

Básico: identificar GET /api/server no openapi.yaml. Intermediário: criar cliente que trate timeout e HTTP 401. Avançado: desenvolver um adaptador de posições com testes automatizados e sem credenciais embutidas. Documente resultados e revise segurança antes de publicar.
