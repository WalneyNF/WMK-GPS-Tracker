Visão geral

Dispositivo GPS → conexão TCP/UDP/HTTP conforme protocolo → classe de protocolo/decodificador Java → processamento e validação → armazenamento de posições e eventos → API REST/WebSocket → interface web.

Estrutura Java

src/main/java/org/traccar contém módulos api, protocol, handler, model, storage, database, geofence, notification, reports, web, session, schedule, command, media, geocoder e outros. A entrada principal é org.traccar.Main.

Frontend

traccar-web/src contém common, login, main, map, reports, settings, store, resources e outros. O projeto usa React, Vite e bibliotecas de mapas. traccar-web/simple/index.html é uma interface alternativa reduzida, não o frontend principal.

Dados centrais

Usuários possuem permissões sobre dispositivos; dispositivos possuem identificador único e posições; posições possuem localização e dados telemétricos; eventos representam ocorrências; geocercas e notificações definem regras e comunicação.

Exercício

Localize org/traccar/Main.java, org/traccar/api/resource/DeviceResource.java e traccar-web/src/main. Faça um diagrama do caminho de uma posição desde a rede até a tela.
