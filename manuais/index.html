Objetivo

Estudar a instalação local do Traccar 6.17.0, sua operação e seu código-fonte. Esta documentação não substitui a documentação oficial e distingue testes confirmados de procedimentos a validar.

Estado verificado

Compilação Gradle assemble: BUILD SUCCESSFUL. Servidor Java inicializado com banco H2 e migrações Liquibase concluídas. API GET /api/server retornou HTTP 200. Interface simplificada exibiu mapa, Add device e Logout. Interface React completa ainda não foi validada.

Ordem de estudo

Comece pela arquitetura; depois instalação e banco; operação e dispositivos; protocolos; API; geocercas e relatórios; interface React e tradução; segurança; testes; e integração futura.

Regras de trabalho

Preservar o código original e a identidade visual do fork; trabalhar apenas no Traccar nesta etapa; manter dados de teste identificados como simulados; nunca publicar credenciais ou abrir o serviço na internet sem configuração de segurança.
