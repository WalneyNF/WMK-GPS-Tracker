Mapa de código

Backend em D:\Ferramentas\traccar\src\main\java\org\traccar. Frontend principal em traccar-web\src. Laboratório independente em laboratorio-gps. Interface atual em traccar-web\simple\index.html.

Backend

org.traccar.Main inicializa o servidor; os pacotes protocol interpretam mensagens de dispositivos, api/resource expõe endpoints REST, storage/database persistem dados e reports/geofence/notification implementam funcionalidades especializadas.

Frontend

O painel principal usa React/Vite; a interface de laboratório é uma página separada com MapLibre e JavaScript. Não confunda o laboratório com o frontend completo nem substitua arquivos de produção por testes.

Simulador

simular-carros.py contém VEICULOS, rotas e interpolate(). Envia GET HTTP à porta 5055 com id, lat, lon, speed em nós, bearing e timestamp. A velocidade exibida em km/h corresponde a speed × 1,852. Os dados são sintéticos.

Conector

wmk_connector.py implementa uma API HTTP JSON somente leitura em 127.0.0.1:8765. Endpoints: /health, /api/v1/contract, /api/v1/vehicles, /api/v1/positions. Esta versão lê arquivos JSONL, não a API autenticada do Traccar.

Contrato de dados

Cada veículo tem id, name, type, source, simulated, color e position. position contém latitude, longitude, speedKmh, heading, timestamp e delivery. source=wmk-gps-lab, simulated=true. Não misture essas posições com telemetria real.

Integração planejada

Próxima fase: adaptador que consulte a API autenticada do Traccar, normalizador de telemetria, cache com expiração, autorização por dispositivo e camada Cesium opcional no WMK. A camada deve ser desligável e preservar a arquitetura atual do WMK.

Segurança

A API experimental é somente loopback, sem autenticação. Nunca exponha a porta 8765 externamente. Para acesso remoto, crie autenticação, autorização, TLS e proteção de credenciais no backend. O CORS restrito não substitui autenticação.

Teste mínimo

Validar Python com py -3 -m py_compile; GET /health, /api/v1/vehicles; POST bloqueado 405; servidor Traccar GET /api/server HTTP 200; testar mapa no navegador e conferir movimentação com simulador. Fazer testes de regressão antes de integrar.
