Ambiente confirmado

Projeto em D:\Ferramentas\traccar. JDK em D:\jdk (Java 23.0.1); o build declara sourceCompatibility/targetCompatibility Java 21. Gradle Wrapper 9.8.2. Banco de desenvolvimento H2 em target/database.

Compilação Java

No PowerShell: $env:JAVA_HOME='D:\jdk'; $env:PATH="D:\jdk\bin;$env:PATH"; $env:GRADLE_USER_HOME='D:\Ferramentas\WMK-Geo-Intelligence\.gradle-cache'; cd D:\Ferramentas\traccar; .\gradlew.bat assemble --no-daemon --console=plain. O resultado já foi BUILD SUCCESSFUL.

Execução local

No diretório do projeto: & 'D:\jdk\bin\java.exe' -Xmx768m -jar '.\target\tracker-server.jar' '.\debug.xml'. A configuração debug.xml define banco H2 e web.path=./traccar-web/simple. Não execute duas instâncias apontando para o mesmo H2.

Verificação

Abra http://127.0.0.1:8082/ para a interface simplificada e http://127.0.0.1:8082/api/server para metadados JSON. HTTP 200 foi confirmado em ambos. Não acrescente /** ao endereço.

Banco e migrações

Liquibase criou e atualizou tabelas tc_users, tc_devices, tc_positions, tc_events, tc_geofences e outras. Para estudar a estrutura, consulte schema/ e os changelogs. Faça cópia do arquivo H2 com o servidor desligado antes de experimentos destrutivos.

Diagnóstico

O log registrou conflito na porta GPS 5040; isso não bloqueou a API HTTP. Verifique qual processo ocupa a porta antes de alterar configurações. O npm ci do frontend React ainda não concluiu com sucesso; evite declarar o painel completo operacional.
