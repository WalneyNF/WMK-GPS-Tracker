API WMK GPS Bridge v1.0

Manual de comunicação Traccar ↔ WMK e integração com terceiros

Central de estudosUsuárioDesenvolvedorIntegração

Visão geral e responsabilidades

O Traccar é o servidor de telemetria e o WMK Geo Intelligence é o consumidor geoespacial. O WMK GPS Bridge v1.0 é um serviço HTTP JSON independente, implementado em Python sem bibliotecas adicionais. Traccar mantém seus protocolos, usuários, permissões e posições. O WMK mantém Cesium, camadas e visualização de trânsito. A ponte não mistura tráfego TomTom/OpenStreetMap com telemetria GPS individual.

Arquitetura de comunicação

Fluxo 1: simulador Python → OsmAnd HTTP 5055 → Traccar Java 8082 → API Traccar autenticada → WMK GPS Bridge 8766 → adaptador JS WMK → futura camada Cesium. Fluxo 2, já testado: simulador Python → JSONL local → WMK GPS Bridge 8766 → cliente HTTP. Fluxo 3: sistema externo → POST com X-WMK-API-Key → arquivo external-positions.jsonl. Fluxos 1 e 3 ainda dependem de configuração e validação fim a fim.

Instalação e inicialização

Arquivos em D:\Ferramentas\traccar\laboratorio-gps: wmk_bridge.py, INICIAR-PONTE-API.bat, simular-carros.py e dados JSONL. Execute o BAT ou py -3 wmk_bridge.py. O serviço escuta somente 127.0.0.1:8766. Teste GET http://127.0.0.1:8766/health. Não é necessário alterar o servidor Java nem instalar bibliotecas Python.

Endpoints de leitura

GET /health: disponibilidade e versão. GET /api/v1/capabilities: fontes e estado de configuração (não revela credenciais). GET /api/v1/vehicles?source=simulator: quatro veículos fictícios dos arquivos locais. GET /api/v1/vehicles?source=traccar: consulta /api/devices e /api/positions da API do Traccar. GET /api/v1/external/positions: últimos 100 registros recebidos de sistemas externos. As respostas são JSON UTF-8 com Cache-Control: no-store.

Contrato de resposta

GET /api/v1/vehicles retorna schemaVersion, source, items, count e timestamp. Cada item contém id, deviceId, name, source, simulated e position. position contém latitude, longitude, speedKmh, heading, timestamp e, quando disponível, valid. Latitude/longitude são graus decimais WGS84; heading em graus; speedKmh em km/h; timestamp ISO 8601. A velocidade original do Traccar está em nós e é multiplicada por 1,852. simulated=null na fonte Traccar significa que a ponte não pode inferir se a posição é real ou simulada.

Autenticação no Traccar

A API oficial suporta sessão/cookie, autenticação HTTP e bearer token. A ponte usa WMK_TRACCAR_TOKEN ou o par WMK_TRACCAR_USER e WMK_TRACCAR_PASSWORD. Configure essas variáveis de ambiente apenas na sessão que inicia o processo; não coloque senhas no HTML, no JavaScript do navegador, em arquivos versionados ou em URLs. Sem credencial, source=traccar retorna HTTP 503 traccar_auth_not_configured. Em caso de falha da API remota, retorna HTTP 502. A URL do Traccar é restrita a localhost nesta versão.

Exemplo PowerShell de configuração

No PowerShell, antes de iniciar a ponte: $env:WMK_TRACCAR_TOKEN = 'COLE_AQUI_UM_TOKEN_GERADO_NO_TRACCAR'; cd D:\Ferramentas\traccar\laboratorio-gps; py -3 wmk_bridge.py. Não copie token real para os manuais. Para limpar a variável: Remove-Item Env:WMK_TRACCAR_TOKEN. Alternativamente configure WMK_TRACCAR_USER e WMK_TRACCAR_PASSWORD. Crie usuário de integração com permissões mínimas quando possível.

Publicação de dados de outros sistemas

POST /api/v1/external/positions aceita JSON com id, latitude, longitude e simulated opcional. Exige cabeçalho X-WMK-API-Key e variável de ambiente WMK_BRIDGE_WRITE_KEY configurada antes da inicialização. Sem chave, retorna 403. Chave incorreta retorna 401. Payload inválido retorna 400. Sucesso retorna 202 e persiste um registro em external-positions.jsonl. O endpoint não injeta dados no banco do Traccar nem controla veículos físicos.

Exemplo JSON de envio

Corpo: {"id":"veiculo-externo-001","latitude":-22.282,"longitude":-42.533,"simulated":true}. Cabeçalhos: Content-Type: application/json e X-WMK-API-Key: SUA_CHAVE_LOCAL. Exemplo PowerShell: $headers=@{'X-WMK-API-Key'=$env:WMK_BRIDGE_WRITE_KEY}; $body=@{id='teste-api-001';latitude=-22.282;longitude=-42.533;simulated=$true}|ConvertTo-Json; Invoke-RestMethod -Uri 'http://127.0.0.1:8766/api/v1/external/positions' -Method POST -Headers $headers -ContentType 'application/json' -Body $body. Nunca envie chaves por query string.

Consumo por outras linguagens

Qualquer cliente HTTP que leia JSON pode consumir GET /api/v1/vehicles?source=simulator: JavaScript fetch, Python urllib/requests, PHP curl, C#, Visual FoxPro via WinHTTP, Node.js e aplicativos móveis. Não dependem do Cesium. Respeite schemaVersion e trate 401, 403, 502 e 503. Para integração remota, esta versão não deve ser exposta diretamente; é necessário um gateway com TLS, autenticação, autorização, limites de taxa e logs apropriados.

WebSocket e atualização

O Traccar possui /api/socket e publica objetos devices, positions e events. A documentação oficial recomenda WebSocket para atualizações frequentes em vez de polling da API de posições. A ponte v1.0 ainda usa consultas REST sob demanda e não retransmite WebSocket. Em produção, implementar conexão autenticada persistente, reconexão exponencial, deduplicação, cache e SSE/WebSocket próprio no gateway.

Segurança e privacidade

Serviço restrito ao loopback 127.0.0.1; CORS permite somente http://127.0.0.1:4173 e http://localhost:4173. CORS não é autenticação. O endpoint de escrita requer chave própria e permanece desativado por padrão. O endpoint de leitura local não possui autenticação, portanto não deve ser publicado em rede. O Traccar mantém permissões de acesso por usuário. Evite expor localização real, identificadores sensíveis e tokens.

Testes confirmados e pendências

Testes confirmados: sintaxe Python válida; /health HTTP 200; /api/v1/capabilities HTTP 200; /api/v1/vehicles?source=simulator HTTP 200 com quatro veículos; /api/v1/vehicles?source=traccar HTTP 503 sem credencial; POST sem chave HTTP 403. Pendentes: autenticação real com token, teste de POST com chave em processo separado, integração visual Cesium, histórico real, eventos, replay, rotas e WebSocket no gateway.
