O que é

O Traccar recebe dados GPS enviados por rastreadores, aplicativos ou simuladores. O laboratório atual mostra quatro veículos fictícios em Nova Friburgo. A tela principal tem lista de veículos, mapa de ruas, botão Ver todos, cadastro e telemetria.

Abrir e entrar

Com o servidor Java em execução, abra http://127.0.0.1:8082/. Entre com sua conta local. Não compartilhe a senha. Se o servidor estiver parado, a página não carregará.

Entender os números

Dispositivos = cadastros acessíveis. Com posição = dispositivos que possuem coordenadas conhecidas na interface. Esses contadores não são prova de que todos os rastreadores estão transmitindo neste segundo.

Selecionar veículo

Clique em um veículo na lista. O mapa aproxima a última posição e o painel mostra velocidade (km/h), direção (graus), latitude, longitude e horário. Use Ver todos para enquadrar os quatro.

Dados simulados

O laboratório utiliza trajetórias sintéticas e não informa tráfego real. Execute INICIAR-SIMULACAO.bat na pasta laboratorio-gps para enviar novas posições pelo protocolo OsmAnd. Feche com Ctrl+C.

Diagnóstico do mapa

Se ruas não aparecerem, teste internet e acesso ao tile.openstreetmap.org. Se um carro não aparecer, confira o Unique ID, o simulador, a porta 5055 e o horário da última posição. HTTP 200 no simulador não garante, isoladamente, que o navegador atualizou.

Cadastro

Use + Dispositivo para informar identificador único e nome. Para os testes atuais: WMK-NF-CARRO-001 a WMK-NF-CARRO-004. O ID deve corresponder exatamente ao valor enviado pelo simulador.

Limitações atuais

A interface de laboratório ainda não possui editor de rotas, replay, alertas avançados ou relatórios completos. Esses recursos existem como proposta de evolução; não devem ser apresentados como prontos.
