Fonte de referência

A especificação do projeto está em openapi.yaml. Recursos Java observados: DeviceResource, PositionResource, EventResource, GeofenceResource, UserResource, SessionResource, ReportResource, NotificationResource, ServerResource, ProtocolResource, CommandResource, entre outros.

API de servidor

GET http://127.0.0.1:8082/api/server retornou HTTP 200 com version=6.17.0, newServer=true, registration=false. Esse endpoint não comprova login ou disponibilidade de posições.

Autenticação

A interface simplificada usa POST /api/session com formulário email/password para autenticar e POST /api/users para criação inicial. Não envie senhas em URL, logs ou screenshots. Para chamadas autenticadas, respeite o mecanismo de sessão/documentação da versão instalada.

Operações comuns

Consulte a especificação OpenAPI para endpoints de usuários, dispositivos, posições, eventos, relatórios, permissões e geocercas. Antes de executar POST/PUT/DELETE, confira requisitos de autenticação, payload e permissões.

Atualizações em tempo real

O frontend pode receber atualizações por canal WebSocket da API. Verifique no código a rota exata, o contrato de mensagens e o comportamento de reconexão antes de escrever clientes externos.

Exercício

Com sessão autenticada, teste primeiro uma consulta somente leitura. Registre status HTTP, estrutura JSON e tratamento de erro 401/403 sem publicar cookies nem tokens.
