Diferença entre interfaces

traccar-web/simple/index.html é uma página de demonstração simples, que carrega React 17, Babel e MapLibre por CDN. A interface completa fica em traccar-web/src e usa React 19, Vite e outros pacotes. Não use a aparência da tela simplificada para julgar o produto completo.

Execução Vite

O vite.config.js declara porta 3000 e proxy /api e /api/socket para localhost:8082. Após npm ci bem-sucedido, use npm run start para desenvolvimento; npm run build gera traccar-web/build. No momento, a instalação npm está pendente e o Vite ainda não foi confirmado.

Localização

Arquivos pt_BR.json e pt.json estão em traccar-web/src/resources/l10n. O pt_BR.json foi encontrado. Para alterar textos, mantenha as chaves JSON, edite valores e valide JSON e renderização; não substitua traduções sem necessidade.

Mapa

A interface utiliza bibliotecas de mapas e pode depender de provedores de tiles e conectividade. Diferencie falha de mapa, falha de login e falha de API usando DevTools → Network/Console.

Exercício

Localize a tela de login em traccar-web/src/login e uma tela de mapa em traccar-web/src/map. Identifique componentes, Redux/store, chamadas de API e chaves de tradução usadas.
