Separação de responsabilidades

Traccar recebe e persiste telemetria GPS; WMK visualiza e correlaciona dados geoespaciais. Os dois sistemas permanecem independentes nesta etapa.

Arquitetura proposta

Traccar API autenticada → serviço adaptador/gateway → modelo normalizado (id, latitude, longitude, timestamp, speed, heading, source) → camada opcional no globo Cesium WMK. O gateway protege credenciais e controla frequência de atualização.

Cuidados

Evitar credenciais diretamente no JavaScript do navegador, polling excessivo, mistura de dados reais e sintéticos, fusos incorretos, duplicação de posições e perda de rastreabilidade da origem.

Critérios de aceite

Antes de integrar: Traccar React funcional; login testado; dispositivo simulado cadastrado; posições recebidas; histórico consultado; API autenticada validada; documentação de segurança revisada. Nenhuma integração foi executada.
